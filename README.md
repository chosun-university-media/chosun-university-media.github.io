# 조선대학교 언론 관리 플랫폼

설치 없이 실행되는 로컬 웹앱입니다. 조선대학교 보도자료 성과와 언론 모니터링을 확인하는 화면입니다.

## 실행

`index.html`을 브라우저에서 열면 화면 확인은 바로 할 수 있습니다.

학교 홈페이지 보도자료를 자동으로 수집하려면 같은 폴더에서 아래 명령으로 로컬 수집 서버를 실행하세요.

```bash
node server.js
```

이후 `http://127.0.0.1:4180/index.html`로 접속하면 `보도자료 새로고침`이 같은 서버의 `/api/official-releases`를 통해 최근 목록과 상세 페이지를 순차적으로 확인합니다. 하루 1~5건 수준의 신규 보도자료를 전제로 최근 항목만 가볍게 수집합니다.

Windows에서는 `start-platform.cmd`를 더블클릭해도 같은 방식으로 실행됩니다.

데이터는 현재 브라우저의 로컬 저장소에 저장됩니다. 다른 PC나 브라우저로 옮길 때는 우측 상단 백업 버튼으로 JSON 파일을 내려받아 보관하세요.

## 포함 기능

- 학교 홈페이지 보도자료 자동 수집
- 보도자료별 기사화율, 영향력, 지면/온라인 성과 리포트
- 기사 모니터링, 감성/위험도 분류, 영향력 산정
- 이슈 대응방과 공식 입장/Q&A 관리
- 월간 리포트, CSV/JSON 내보내기
